# Articles

All article pages (`*/<slug>/index.html`) are generated by `scripts/build-articles.mjs` from `content/articles`. Read `docs/article-template.md` before creating or changing articles. Edit source content and the shared template, then run `npm run build:articles` and `npm run check:articles`. Do not create independent article layouts or manually edit generated pages. Category and journal indexes are separate.

Keep stable heading IDs, verified sources and existing text. Use hyphens instead of em/en dashes in new editorial prose; avoid «не X, а Y». Drafts remain drafts until their content is complete. Do not invent publication dates or translations.
