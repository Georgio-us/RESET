# Готовность RESET к индексации

Дата: 22 сентября 2026. Проверяем опубликованные документы и серверные ответы. Данные текущего индекса Google не запрашивались в Search Console; техническая доступность не означает фактическую индексацию.

## Стартовый набор

73 уникальных канонических адреса: 4 главные, 60 страниц кейсов (15 кейсов на четырёх языках), русский журнал и два раздела с готовыми материалами, 6 русских статей.

За пределами индекса: черновики статей и переводов, два незаконченных кейса FACTOR SEO и Kommo CRM, разделы без опубликованных статей, служебные презентации и страницы. Их можно открыть по прямой ссылке. Noindex не ограничивает доступ пользователя.

## Выполнено

- Карта сайта пересобрана из HTML с проверкой canonical, наличия страницы, уникальности URL и отсутствия noindex.
- Отложенные разделы и пустые языковые журналы получили noindex,follow. Готовые материалы остаются indexable.
- Восемь страниц двух кейсов получили недостающие meta description на соответствующих языках.
- Известные варианты /index.html, адреса разделов без завершающего слеша и старые корневые адреса материалов/кейсов перенаправляются на основной URL. Несуществующие страницы остаются 404.
- Для исходников и документации /docs/, /content/, /templates/, /scripts/ установлен заголовок X-Robots-Tag: noindex, follow.
- robots.txt разрешает обход и содержит ссылку на sitemap.xml. Черновики не блокируются через Disallow: Google должен прочитать noindex.
- Сборка журнала автоматически обновляет правила индексации и sitemap, чтобы готовая следующая статья появилась в карте сайта.

## Проверки

Исходный HTTP-обход: 106 адресов, включая sitemap и контрольные адреса. Основной домен отвечает, robots.txt доступен, черновик отдаёт noindex,follow, несуществующая страница возвращает 404.

Статическая проверка нового набора: 73 страницы; canonical совпадает с адресом sitemap; один H1; описание присутствует; внутренние ссылки, якоря и подключённые файлы доступны. Ошибок после исправлений нет. Автотесты сборки и канонических перенаправлений проходят.

Открытый вопрос: https://www.resetdigital.agency/ возвращает 404 на уровне инфраструктуры. Редирект www уже есть в приложении, но запрос до него не доходит. Нужна привязка домена в Railway либо перенаправление www на основной домен на уровне DNS-провайдера/CDN. Требуется авторизация владельца. Основной адрес без www работает.

## Search Console

1. В свойстве resetdigital.agency отправить https://resetdigital.agency/sitemap.xml через раздел «Файлы Sitemap».
2. Через «Проверку URL» выполнить живую проверку https://resetdigital.agency/ru/ и приоритетных новых статей, затем запросить индексирование.
3. Проверять отчёты об индексировании с учётом задержки обновления. Статус «Исключено тегом noindex» ожидаем для заготовок.
4. После подготовки следующей статьи поменять status на published, выполнить build:articles и build:journal, опубликовать. Затем при необходимости запросить индексирование её URL.

Текст, заголовки и noindex меняются на сайте. Search Console просит Google перечитать страницу; сервис не редактирует её содержимое и не гарантирует включения в поиск.
