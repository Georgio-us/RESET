KALOFER VILLA3D architectureKalofer / Bulgaria

RESET / CASE STUDY

De los planos al modelo 3D de una villa en Bulgaria.

Para una villa del proyecto cerca de Kalofer desarrollamos los planos, los cuadros de superficies y el modelo volumétrico. Esta base permite avanzar la arquitectura, comprobar decisiones y crear material fotorrealista para presentación y marketing.

2 plantasdistribuciones con usos y superficies

RESET / APPROACH

Un modelo conecta distribución, arquitectura y presentación.

01

Desarrollamos las plantas

Definimos estancias, superficies, escalera, terrazas y conexiones entre niveles.

02

Construimos el volumen

Trasladamos los planos a 3D para comprobar proporciones, acristalamiento, fachadas, cubiertas y espacios abiertos.

03

Preparamos el render

El modelo se convirtió en la base para el desarrollo posterior y el material de marketing de las villas.

PRODUCT / WORKFLOW

Las plantas establecen una base precisa para el modelo.

01 / USOS

Los cuadros fijan el uso y la superficie de cada espacio antes de construir el volumen.

02 / CONEXIONES

Una escalera común conecta los niveles y los huecos se coordinan entre plantas y fachadas.

03 / ESCALA

Las dimensiones y superficies mantienen controladas las proporciones de la villa en las fases siguientes.

El proyecto obtuvo una base espacial coordinada para afinar la arquitectura, preparar material técnico y producir renders finales para presentar el inmueble.
